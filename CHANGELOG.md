# История изменений

## Не выпущено

### Добавлено
- docs/INTEGRATIONS.md (связь с basilisk и citadel) и docs/RESEARCH.md (постановка исследования об атрибуции и её границах, без результатов)
- читатели форматов: универсальный `generic` (docs/FORMAT.md) и `codex` (по описаниям, не проверен на реальных файлах); `--format auto` определяет формат по содержимому (#17)
- `scan` и `report`: параллельный разбор (`-j`), кэш результатов на файл (`--no-cache`); холодный запуск на 77 журналах 6 с в один процесс, 2,3 с в четыре, 0,2 с по кэшу (#17)
- открытый набор данных `dataset/ectoplasm-bench-v1` (75 синтетических сессий, карточка, `labels.json`) и команда `bench` для прогона с precision и recall (#17)
- `ectoplasm hook`: хук PreToolUse для Claude Code, просит подтверждение (или запрещает, или предупреждает) до выполнения действия, связанного с недоверенным текстом; никогда не отдаёт allow, при ошибках пропускает; читает хвост журнала (#15)
- `trace --sarif`, `action.yml` и `docs/CI.md` для GitHub Actions (workflow в настоящем Actions не запускался) (#15)
- `report`: сводка по папке журналов (по уровню связи, действию, источнику текста, дням) в тексте, JSON и HTML (#15)
- `rules`: правила в JSON, чтобы шлюз или другой инструмент использовал те же признаки (#15)
- связь «смертельная тройка»: в одном ходе недоверенный текст (веб, MCP, скачанный код), затем доступ к данным (чтение секретов или ресурс, которого пользователь не называл), затем отправка наружу; не больше 40 событий между текстом и отправкой (#13)
- слабые метки инструкции «давление» и «захват области»; нужны две разные, чтобы стать связью (#13)
- `trace --judge-cmd`: внешний судья для перефразированных инструкций, модель в пакет не входит (#13)
- локальные адреса (localhost) больше не считаются недоверенным источником; `.env.example` и подобные файлы не считаются секретами
- разбор десяти публичных атак на агентов (`docs/CASES.md`) и набор `public` в корпусе: 12 сценариев (7 атак, 5 обычных) и 4 заведомо невидимых, которые тест держит невидимыми (#10)
- скрытый текст (невидимый Unicode от 8 символов) ищется во всём, что агент прочитал, включая файлы правил и контекст клиента, и показывается расшифрованным; отдельная находка, код возврата 1, колонка в `scan`
- новые действия: запись во внешний сервис через MCP, запрос к таблицам с секретами через MCP, подмена окружения (`PAGER`, `LD_PRELOAD`, `BASH_ENV`...), запуск другого агента без подтверждений, удаление облачных ресурсов
- признак «инструкции для ассистента» по имени (Cursor, Claude, Copilot, assistant, agent)
- `trace --html` и `demo --html`: самодостаточный HTML-отчёт с временной шкалой сессии, источниками и цепочками (без скриптов, CSP, всё экранируется) (#5)
- команда `scan`: пройтись по папке с журналами и показать, где есть связи; `demo` теперь показывает рабочий день агента, а не короткий пример
- корпус из 54 размеченных синтетических сессий (`tests/corpus`, 14+8+5 атак и 16+9+2 обычных, разбит на подборочный, отложенный и «трудный» наборы), скрипт `scripts/eval.py` и регрессионный тест (#7)
- связь по пути: чувствительный файл (`.env`, ключи, `CLAUDE.md`, `.mcp.json`, `.zshrc`) назван недоверенным текстом, а пользователем нет (#3)
- признак «приказ выполнить» сам по себе больше не считается подозрительным: нужен сильный признак или два разных
- файлы, полученные извне (`git clone`, `gh repo clone`, `curl -o`, `wget`, распаковка), и сторонний код считаются недоверенным источником; серверы самого клиента (`mcp__ccd_*` и др.) нет (#4)
