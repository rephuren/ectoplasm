# Как это стыкуется с остальными проектами

Три проекта из одного портфеля закрывают три момента жизни атаки. Они не зависят друг от друга по коду: стыковка идёт через файлы и правила.

| момент | проект | что делает | что остаётся за границей |
| :-- | :-- | :-- | :-- |
| **до** | basilisk | статический аудит MCP-серверов и описаний инструментов: опасные определения, закрепление и проверка подмены (`pin`, `verify`) | не видит, что сервер делает внутри (поддельный `postmark-mcp` с копией писем остаётся невидимым) |
| **во время** | citadel | шлюз между агентом и MCP-серверами: политики, taint tracking с режимом «тройки», очистка скрытых символов, подтверждения человеком | видит только MCP-вызовы, а не команды оболочки и правки файлов, которые агент делает сам |
| **после и рядом** | ectoplasm | разбор журнала сессии, `hook` перед действиями агента (оболочка, файлы, MCP), связь «текст → действие» | работает по журналу: если текста, который привёл к действию, в журнале нет, связи не будет |

## Что можно соединить сейчас

- **Правила как данные.** `ectoplasm rules > rules.json` выдаёт признаки инструкции, опасные действия и порядок источников. Шаблоны в синтаксисе Python `re`; у JavaScript отличаются встроенные флаги (`(?i)`), их при переносе в citadel нужно заменить флагом `i`. Автоматического импорта в citadel нет.
- **Две проверки одного и того же.** citadel блокирует «тройку» по меткам, которые вы расставили в политике; ectoplasm находит её по журналу без разметки. Расхождение между ними хороший сигнал: либо в политике не хватает метки, либо журнал показывает действие мимо шлюза (оболочка, правка файла).
- **Хук как «шлюз для всего остального».** citadel стоит на MCP, а `ectoplasm hook` стоит перед любым инструментом Claude Code, включая `Bash`, `Write`, `Edit`. Вместе они покрывают и MCP, и локальные действия.

## Чего пока нет

- Нет общего журнала: журнал citadel не хранит значения аргументов (по замыслу), поэтому ectoplasm не может его разбирать как сессию. Связь возможна по времени и по именам инструментов, но не по содержимому.
- Нет проверки «правила citadel соответствуют ectoplasm» автоматически.
- Нет единого релиза: версии и форматы у проектов независимые.
